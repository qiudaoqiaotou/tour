## 4. 城市筛选逻辑（问题 2）

从「人流量不高、有一定知名度、国庆前后人流差距不大（避免过度景区营销风险）」三个目标出发，对每个候选城市打分（1–5 分）：

- **C 人流量（crowd）**：国庆期间预期人流量越小越好（5 = 很空，1 = 人山人海）。
- **F 知名度（fame）**：作为旅游目的地的公开认知度（5 = 全国知名，1 = 小众到无感）。
- **S 人流稳定性（stability）**：国庆前后人流波动越小越好（5 = 常年稳定，1 = 暴起暴跌）。用于识别「过度景区营销」风险：一个靠网红/病毒式营销冲起来的景区，特征是人流在假期猛增、节后断崖，即 C 峰与 C 基 差距大、S 低。
- **M 营销风险（over-marketing risk）**：越低越好（5 = 无营销炒作，1 = 明显靠营销带流量）。证据：爆火叙事、封神/网红景区、文旅局长营销事件、被官方/媒体点名的流量景区等。

**候选判定**：`入选 = (F ≥ 3) 且 (C ≥ 3) 且 (S ≥ 3) 且 (M ≥ 3)`，总分 `T = C + F + S + M`，取 T 靠前者为推荐城市。凡 C 峰/基差距大、M 低（营销炒作）者**排除**。

## 5. 交通口径（问题 3）

- 覆盖 **上海（出发）⇄ 候选城市** 的往返路线，窗口 **9/20–10/10**。
- 记录每种方式的：方式（高铁/动车/普速/飞机/大巴/自驾/轮渡）、单程时长、参考票价、班次/频率、是否直达。
- 溢价观察：以「平日价」为基准，比较国庆期间票价上浮（溢价率）；推荐 **溢价低** 且 **绝对价低** 的组合。标注数据为 [estimate] 时说明依据。

## 6. 住宿与行程口径（问题 4）

- 在候选城市内，选 1 家推荐酒店：直达/近景区、有接驳/专车、若为特色酒店（如温泉）优先。
- 给出 3–5 天（含往返）行程：景点、时间分配、交通接驳、饮食。

## 7. 签证口径（问题 5）

- 仅当推荐城市在境外时给出：签证类型、办理流程、材料、**典型办理时间（工作日）**、申请渠道（使馆/领馆/e-visa 网站）、费用。
- 政策按 2026 年现状核实；无法核实标 `[unverified]`。

## 8. 重要提醒

- 2026 国庆为「预测/预估为主」：本看板对每条数据标注来源与 as-of 日期；无公开来源处用历史行为估算并**明确标注 `[estimate]`**。
- 本看板是**决策参考**，不提供任何预订；具体价格、班次、签证以官方/平台实时为准。
